# ChatHistory 3.0 — Python 聊天记录管理系统

## 1. 项目介绍

ChatHistory 3.0 是一个基于 Python 开发的命令行聊天记录管理程序。

项目实现了聊天记录的添加、读取、JSON 文件持久化、异常处理及历史记录数量限制等功能，并使用环境变量进行配置管理。

本项目是 AI Agent 开发学习过程中的基础实践项目，为后续接入大语言模型 API、构建多轮对话系统打下基础。

## 2. 项目功能

- **聊天记录管理**：支持添加、查看和清空聊天记录。
- **JSON 数据持久化**：支持将聊天记录保存到 JSON 文件，并在下次启动程序时恢复。
- **异常处理**：处理文件不存在、JSON 文件格式错误以及用户输入为空等情况。
- **历史记录数量限制**：根据 `MAX_HISTORY` 配置，仅保留最新的指定数量的消息。
- **环境变量管理**：通过 `.env` 文件管理应用名称、聊天记录保存路径及最大记录数量。
- **自动创建目录**：使用 `pathlib` 创建聊天记录所需的文件夹。

## 3. 技术栈

| 技术 | 用途 |
|---|---|

## 5. 安装与运行

### 第一步：安装依赖

确保已安装 Python，然后在项目目录下运行：

```bash
python -m pip install python-dotenv
```

### 第二步：配置环境变量

将 `.env.example` 复制并重命名为 `.env`。

在 `.env` 中配置：

```ini
APP_NAME=ResearchAgent
HISTORY_FILE=data/history.json
MAX_HISTORY=3
```

各配置项说明：

- `APP_NAME`：应用名称。
- `HISTORY_FILE`：聊天记录保存路径。
- `MAX_HISTORY`：最多保留的聊天消息数量，必须为正整数。

### 第三步：运行程序

在项目根目录执行：

```bash
python main.py
```

程序启动后，可根据提示输入消息。

## 6. 运行示例

**第一次运行：**

```text
欢迎使用ResearchAgent
历史记录文件不存在
加载的旧聊天记录为：0条
请输入消息：你好
当前聊天记录数量为1条
```

**第二次运行：**

```text
欢迎使用ResearchAgent
加载的旧聊天记录为：1条
请输入消息：今天学习Python
当前聊天记录数量为2条
```

当消息数量超过 `MAX_HISTORY` 时，程序会自动删除最早的记录，只保留最新消息。

## 7. 异常处理

本项目针对常见问题提供了异常处理机制：

| 异常情况 | 处理方式 |
|---|---|
| 历史记录文件不存在 | 从空聊天记录开始 |
| JSON 文件格式损坏 | 输出错误并停止，避免覆盖原文件 |
| 输入为空或只有空格 | 提示输入错误，不保存消息 |
| `MAX_HISTORY` 小于或等于 0 | 抛出 `ValueError` |
